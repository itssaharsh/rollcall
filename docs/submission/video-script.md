# Rollcall — demo script (264s)

**hook** `0:00.0` Every insurer publishes a list of doctors. Most of it is wrong, and by law someone has to phone every office to fix it. [[0.3]] Rollcall makes the calls.

**problem** `0:11.0` Senate staff phoned a hundred and twenty listed therapists. They could book an appointment eighteen percent of the time. Retired, moved, wrong number, not taking that plan.

**law** `0:23.1` Nobody chooses to make these calls. Three US rules require them, from every health plan, every ninety days.

**sweep** `0:31.4` Meet Rollcall. Forty listings, unchecked for a year. One click. [[0.3]] Six lines dial six offices at once. Each call checks five things: still here, address, phone, new patients, in network. Every clear answer lands in its cell. A correction shows the old value struck through. A retired doctor gets flagged for removal. [[0.3]] Forty calls later, the register is done.

**clipA** `0:57.7` Every change has a receipt. Row seven moved in June. Listen.

**clipB** `1:08.5` The cell, the words that filled it, and the audio they came from. Below, the whole call, with every tool call the agent made.

**review** `1:15.0` Some answers are not clear enough to write down. I think so, is not a fact. Those wait for a person, with the clip attached, until a person decides.

**refused** `1:27.2` And here is what a prompt can't do. The office said, I think it is five thirty. The model tried to write that address. The gate refused and sent the reason back. The agent asked again, got another maybe, so it stays unwritten, and a human gets the call.

**call-intro** `1:42.7` Now it calls you, and you play the front desk. This is a real call with the same agent. The office changed suites, and hedged on new patients.

**call-live** `1:53.2` *(no narration)*

**call-result** `2:28.8` A minute later the call ends. Suite three became suite four, the number stayed, and new patients got a question mark, because, I think she might be, is not an answer. You are now row forty-one.

**report** `2:46.2` Then the plan files this: an attestation sheet, every correction with the receptionist's words, and a spreadsheet for the directory team.

**tech** `2:54.2` Each row becomes the call's key terms, so names and streets are heard right. AssemblyAI's Voice Agent API runs both ends of every recorded call, and the live one in your browser. **competition** `3:47.2` Today this is call centres, or enterprise vendors selling closed systems to the biggest plans. Rollcall keeps the audio behind every value, refuses to guess, and publishes its score.
